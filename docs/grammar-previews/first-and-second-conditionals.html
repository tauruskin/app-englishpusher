🧳 First and Second Conditionals

Lesson 7A — 25 questions · 8 cards

Gap Fill

If it rains tomorrow, we ___ the match.

Answer: will cancel

If + present simple, ... will + base verb — the classic first conditional pattern.

You'll feel more relaxed if you ___ your bags the night before.

Answer: pack

If + present simple (not will) describes the real condition; will only goes in the main clause.

If I ___ a map, I wouldn't get lost in the old town.

Answer: had

If + past simple (not would) sets up the imaginary condition; would only goes in the main clause.

If the museum were free, more local people ___ it.

Answer: would visit

Would + base verb = the imagined result of a hypothetical if-clause.

If you don't reserve a table, the restaurant ___ full by the time you arrive.

Answer: will be

Negative if-clause, positive main clause: If you don't ..., ... will still happen.

If the flight ___ cheaper, more people would book it.

Answer: were

Formal second conditional: If + subject + were ..., not 'was' — common with I/he/she/it too.

Error Spot

If you travel in summer, the city will being very crowded.

Correction: be

First conditional main clause needs will + base verb: 'will be', not 'will being'.

If I have more free time, I would travel to Asia.

Correction: had

A second conditional if-clause needs the past simple: 'If I had...', not the present simple 'have'.

If you don't booking soon, the flights will be more expensive.

Correction: book

After 'don't', use the base verb: 'don't book', not 'don't booking'.

If we stayed in a small hotel, we will help the local economy.

Correction: would

A second conditional main clause needs 'would', not 'will', to match the past simple if-clause 'stayed'.

If the city charge a tourist tax, it will reduce the crowds.

Correction: charges

The present simple needs -s with a singular subject: 'the city charges', not 'the city charge'.

If local shops sold fewer plastic bags, the beaches would being cleaner.

Correction: be

The second conditional main clause needs would + base verb: 'would be', not 'would being'.

Multiple Choice

Which sentence correctly forms the first conditional?

Answer: If you visit Kyoto, you will see beautiful temples.

If + present simple, + will + base verb. Never 'will' in the if-clause.

Which sentence correctly forms the second conditional?

Answer: If I had more money, I would travel first class.

If + past simple, + would + base verb. Never 'would' in the if-clause.

What does this sentence tell us about the plan? ("If you book a guided tour, you'll learn more about the history.")

Answer: Booking a tour is a real, realistic possibility — this is a first conditional.

First conditional = a real, possible plan — not just an imaginary idea.

What kind of situation does this describe? ("If I spoke Japanese, I could get a job as a tour guide here.")

Answer: A hypothetical situation — in reality, the speaker doesn't speak Japanese.

Second conditional = an imaginary situation that isn't true right now.

Which sentence is grammatically correct? (about advertising tourist spots)

Answer: If we advertise other places, more tourists will visit them.

Don't mix tenses: present simple if-clause + will-clause, all the way through.

Which sentence uses the comma correctly?

Answer: If you travel by train, you'll avoid traffic jams.

If-clause first → comma. If-clause second → no comma.

Which sentence gives advice correctly?

Answer: If I were you, I'd avoid travelling in peak season.

If I were you, I'd... — a fixed phrase for advice. Always 'were'.

Word Transform

If the weather ___ (improve) this weekend, we'll visit the old town.

Answer: improves

Present simple + -s for he/she/it, even inside an if-clause.

If we leave now, we ___ (catch) the early train.

Answer: will catch

Will + base verb, never will + -s or will + -ing.

If I ___ (speak) the language, I would feel more confident travelling alone.

Answer: spoke

Second conditional if-clause = past simple, even for irregular verbs: speak → spoke.

If the museum offered online booking, fewer tourists ___ (wait) in long queues.

Answer: would wait

Would + base verb for the imagined result of a hypothetical if-clause.

If the airline cancels the flight, passengers ___ (receive) a refund.

Answer: will receive

Will is the same for every subject: I/you/he/we/they will + base verb.

If I ___ (be) you, I'd book the hotel in advance.

Answer: were

If I were you, ... — a fixed phrase for advice; always 'were', never 'was'.

Flashcards

First conditional: if + present simple, + will

If you ___ (book) early, you'll get a cheaper flight.

Back: If you book early, you'll get a cheaper flight. Answer as book

The first conditional describes a real, possible situation in the future: if + present simple, will + base verb.

If it rains, we'll stay at the hotel. · If you arrive late, you'll miss the tour.

First conditional = реальна майбутня умова: if + Present Simple, will.

The if-clause can come first or second

You'll save money if you ___ (travel) out of season.

Back: You'll save money if you travel out of season. Answer as travel

The if-clause can come first (If you travel out of season, you'll save money) or second (You'll save money if you travel out of season). Use a comma only when if comes first.

If we leave now, we'll avoid the traffic. · We'll avoid the traffic if we leave now.

If-речення може стояти першим (з комою) або другим (без коми).

Second conditional: if + past simple, + would

If I ___ (have) more holiday, I'd travel more.

Back: If I had more holiday, I'd travel more. Answer as had

The second conditional describes a hypothetical or unlikely situation: if + past simple, would + base verb.

If she spoke French, she'd apply for the Paris job. · If we stayed longer, we'd see more of the city.

Second conditional = уявна умова: if + Past Simple, would.

If I were you (not was)

If I ___ (be) you, I'd pack a lighter suitcase.

Back: If I were you, I'd pack a lighter suitcase. Answer as were

In the second conditional, 'were' is the standard form of 'be' for every subject, including I/he/she — 'was' is only informal.

If he were older, he'd travel alone. · If it were cheaper, I'd visit twice a year.

У другому conditional частіше кажуть were, навіть для I/he/she, не was.

will only in the main clause

If the flight ___ (be) delayed, we'll miss the connection.

Back: If the flight is delayed, we'll miss the connection. Answer as is

In a first conditional, the if-clause never has 'will' — it uses the present simple. 'Will' only appears in the main clause.

If you don't hurry, you'll miss the bus. · If the shop is closed, we'll come back tomorrow.

В if-частині ніколи немає will — тільки Present Simple.

would only in the main clause

If I ___ (know) the language, I'd feel more confident.

Back: If I knew the language, I'd feel more confident. Answer as knew

In a second conditional, the if-clause never has 'would' — it uses the past simple. 'Would' only appears in the main clause.

If they offered a discount, we'd stay longer. · If the museum were open, we'd visit today.

В if-частині ніколи немає would — тільки Past Simple.

First = real plan, second = imaginary idea

If I ___ (go) to Peru next year, I'll see Machu Picchu.

Back: If I go to Peru next year, I'll see Machu Picchu. Answer as go

Use the first conditional for a real plan you might actually do. Use the second conditional for an imaginary idea: If I went to Peru, I'd see Machu Picchu.

If we visit Japan, we'll try sushi in Tokyo. · If we visited Japan, we'd try sushi in Tokyo.

First = реальний план; second = уявна чи малоймовірна ідея.

Contractions: 'll and 'd in speech

If you ask politely, people ___ (will) usually help you.

Back: If you ask politely, people will usually help you. Answer as will

In speech, will often contracts to 'll (you'll, it'll) and would to 'd (I'd, we'd). Both full and contracted forms are correct in writing.

I'll call you when the train arrives. · We'd love to visit again next year.

У розмові will → 'll, would → 'd: you'll, we'd.
